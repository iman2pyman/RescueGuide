# راه‌اندازی خرید درون‌برنامه‌ای کافه‌بازار

## مدل فروش انتخاب‌شده
- نوع کالا: خرید درون‌برنامه‌ای یک‌باره و دائمی (محصول غیرمصرفی / Managed Product).
- خرید موفق باید پس از بازیابی خریدها نیز فعال بماند.
- برای این محصول نباید `consumeProduct` اجرا شود؛ مصرف‌کردن، امکان خرید مجدد را ایجاد می‌کند.
- تمام مسیرهای ضروری BLS، راهنمای صوتی حیاتی، شمارشگر CPR و تماس اضطراری ۱۱۵ رایگان می‌مانند. فقط محتوای آموزشی/تکمیلیِ غیراضطراری می‌تواند Premium باشد.
- شناسه محصول `rescueguide_full_access` و کلید عمومی RSA در نسخه 0.42.0 در کد تنظیم شده‌اند. فعال‌شدن دسترسی فقط با تأیید SDK کافه‌بازار یا بازیابی مالکیت انجام می‌شود.

## اطلاعاتی که باید از پنل توسعه‌دهندگان بازار برداشته شود
۱. وارد پنل توسعه‌دهندگان کافه‌بازار شوید و برنامه RescueGuide را باز کنید.
۲. در بخش پرداخت درون‌برنامه‌ای، یک محصول جدید از نوع خرید یک‌باره/غیرمصرفی بسازید.
۳. شناسه یکتای محصول (Product ID / SKU) را دقیقاً همان‌طور که پنل نشان می‌دهد کپی کنید. این مقدار را تغییر ندهید.
۴. عنوان فارسی و قیمت را در پنل تعیین کنید. عنوان و قیمت باید روشن کنند که این خرید دائمی است.
۵. کلید عمومی RSA مخصوص برنامه را از بخش تنظیمات پرداخت درون‌برنامه‌ای کپی کنید. کلید عمومی محرمانه نیست، اما باید کامل و بدون فاصله/کاراکتر اضافی منتقل شود.
۶. قبل از انتشار، برنامه باید در بازار ثبت شده باشد و خرید با نسخه نصب‌شده از مسیر بازار روی دستگاه واقعی آزمایش شود.

## نکات امنیت و آزمون
- فقط RSA Public Key در برنامه قرار می‌گیرد؛ کلید خصوصی RSA هرگز در APK یا مخزن قرار نمی‌گیرد.
- خرید تنها پس از callback موفق SDK و بازیابی/تأیید مالکیت فعال می‌شود.
- لغو خرید، قطع اتصال، نبود برنامه بازار و خطا نباید Premium را فعال کنند.
- نصب برنامه بازار روی دستگاه برای اجرای جریان پرداخت لازم است.
- خرید دائمی باید با `getPurchasedProducts` بازیابی شود؛ برای این کالا `consumeProduct` فراخوانی نشود.
- پیاده‌سازی اولیه Poolakey در شاخه `feature/bazaar-permanent-access` انجام شده است. خرید واقعی هنوز باید با نسخه نصب‌شده از بازار و حساب آزمایشی/واقعی روی دستگاه بررسی شود.

## اطلاعاتی که برای ادامه پیاده‌سازی لازم است
در پیام بعد فقط این دو مورد را ارسال کنید:
- شناسه محصول (SKU / Product ID)
- کلید عمومی RSA کافه‌بازار

کلید امضای اندروید، فایل keystore و رمز آن را در چت یا مخزن GitHub ارسال نکنید.

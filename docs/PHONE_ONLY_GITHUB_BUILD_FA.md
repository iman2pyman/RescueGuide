# دریافت APK با گوشی از GitHub Actions

1. مخزن RescueGuide را باز کنید و وارد تب **Actions** شوید.
2. آخرین اجرای `RescueGuide Android CI` را انتخاب کنید.
3. صبر کنید تا همه jobها تمام شوند؛ اجرای موفق با علامت سبز مشخص می‌شود.
4. در پایین جزئیات همان اجرا، قسمت **Artifacts** را پیدا کنید.
5. فایل `rescueguide-debug-apk` را دانلود و در گوشی Extract کنید.
6. APK داخل پوشه استخراج‌شده قرار دارد. نصب آن ممکن است نیازمند اجازه نصب از همین منبع در تنظیمات Android باشد.

اگر اجرا قرمز شد، APK موفقی تولید نشده است. از بخش قرمز workflow، متن اولین خطا و چند خط اطراف آن را ارسال کنید؛ صرفاً دانلود artifact گزارش خطا کافی نیست.

این APK در صورت موفقیت workflow فقط نسخه debug توسعه‌ای است. پیش از استفاده واقعی، نصب و آزمون روی گوشی، ارزیابی کیفیت فایل‌های صوتی، و بازبینی نهایی مسیرهای بالینی ضروری است. این برنامه جایگزین اپراتور ۱۱۵ یا آموزش عملی نیست.

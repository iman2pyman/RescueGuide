# RescueGuide 0.37.0-dev

اپلیکیشن اندرویدی فارسی برای راهنمای صوتی و تصویری احیای پایه (BLS) در بزرگسال، کودک و شیرخوار.

## امکانات نسخه
- صفحه آغازین پزشکی با انتخاب جداگانه بزرگسال، کودک و شیرخوار؛ ایران و شماره اورژانس ۱۱۵.
- صفحه انتخاب نوع امدادگر با دو گزینه «امدادگر آموزش‌دیده» و «فرد عادی».
- راهنمای صوتی MP3 فارسی و آفلاین؛ مراحل پس از پایان پخش به‌صورت خودکار پیش می‌روند و برای اقدام حیاتی منتظر تأیید «بله» نمی‌مانند.
- کنترل‌های «مرحله قبل» و «تکرار توضیح فعلی».
- دکمه بزرگ «علائم حیاتی برگشت» و صفحه مستقل مراقبت پس از ROSC با شش مرحله متنی و تصویری، بدون راهنمای صوتی.
- تنظیمات شامل فقط سه گزینه: تم شب/روز (ذخیره‌شونده)، راهنمای برنامه و درباره سازنده.
- تصاویر آموزشی آفلاین و بزرگ‌نمایی‌پذیر؛ منابع و مجوزها در `docs/IMAGE_ASSET_LICENSES.md`.
- ۳۴ فایل MP3 همراه برنامه و مترونوم CPR با بازه ۱۰۰ تا ۱۲۰ فشار در دقیقه.
- آیکن اختصاصی RescueGuide و شماره‌گیر اورژانس ایران ۱۱۵.

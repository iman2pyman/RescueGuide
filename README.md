# RescueGuide

اپلیکیشن اندرویدی فارسی برای راهنمای مرحله‌به‌مرحله احیای پایه (BLS) در بزرگسال، کودک و شیرخوار.

## امکانات موجود در سورس
- رابط کاربری فارسی با تم پزشکی و آیکن اختصاصی قلب/نوار قلب
- مسیرهای احیای پایه برای بزرگسال، کودک و شیرخوار
- انتخاب جداگانه بزرگسال، کودک و شیرخوار و سپس انتخاب فرد عادی یا امدادگر آموزش‌دیده
- دستورهای صوتی فارسی آفلاین به‌صورت MP3 همراه برنامه
- راهنمای صوتی خودکار بدون انتظار برای تأیید؛ دکمه‌های مرحله قبل، تکرار و گزارش بازگشت علائم حیاتی
- مترونوم CPR قابل تنظیم ۱۰۰ تا ۱۲۰ فشار در دقیقه
- صفحه مراقبت پس از بازگشت علائم حیاتی، بدون راهنمای صوتی
- تصاویر آموزشی آفلاین با مجوز بازاستفاده و بزرگ‌نمایی؛ فهرست کامل مجوزها در docs/IMAGE_ASSET_LICENSES.md
- تنظیمات تم شب/روز، راهنمای برنامه و معرفی سازنده
- شماره‌گیر اورژانس ایران ۱۱۵

## دامنه و هشدار
این نسخه فقط شامل احیای پایه (BLS) است؛ احیای پیشرفته در محدوده نیست. برنامه جایگزین تماس با اورژانس، دستور اپراتور یا آموزش عملی نیست. صدای فارسی همراه برنامه ماشینی است و باید روی گوشی واقعی ارزیابی شود. هنوز APK نهایی ساخته و روی دستگاه واقعی تأیید نشده است.
